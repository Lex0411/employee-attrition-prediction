Business Problem

Employee attrition prediction helps HR and management see which employees are likely to leave the company. Early insight supports retention plans, hiring, and cost control.

Predictive Modeling Workflow

  1. Problem identification — Will the employee leave? (Yes / No)
  2. Data collection — Upload CSV/Excel or use the sample dataset
  3. Data preprocessing — Missing values, encoding, scaling, train/test split
  4. Feature selection — All employee attributes except Attrition
  5. Model training — KNN, SVM, and ANN
  6. Model testing — Hold-out test set (20%)
  7. Performance evaluation — Accuracy, Precision, Recall, F1, Confusion Matrix
  8. Prediction output — Predict attrition for a new employee

Algorithms Used

KNNK-Nearest Neighbor — classifies by similar employees in the training data
SVMSupport Vector Machine — finds a boundary between leave / stay groups
ANNArtificial Neural Network — learns patterns through hidden layers
